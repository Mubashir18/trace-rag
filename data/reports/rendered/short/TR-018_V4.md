## SUMMARY
An actor tracked here as LINEN SWIFT (fictional) sends consulting firms an e-mail asking staff to
"review an HR document". The link opens a real-looking sign-in prompt that asks the user to let an
application called Tallowmint read their files. No password is stolen and no malware is installed:
the user simply grants the app access. The actor then downloads shared files through the app.
Hosts that opened the consent page or talked to the app's back end should be reviewed.

## TECHNICAL DETAILS
### Initial Access
The lure links to consent-review-app[.]example[.]net, which starts a standard consent flow for the
Tallowmint application [T1566.002]. Users who click "accept" grant the app read access to their
files [T1528].
### Collection
The app's back end, tm-graph-proxy[.]example[.]org, lists and downloads files that the user can
reach [T1213]. Some requests from the victim's browser go directly to 203.0.113.197.
### Infrastructure
