# Compromised Partner Portal Serving Trojanized Invoices with the "Emberquill" Macro Loader

## ACTIONS TO TAKE TODAY
1. Search proxy and DNS logs for the network indicators in Table 1.
2. Search EDR alerts for the document hash in Table 2 and isolate matching hosts.
3. Block macros in documents downloaded from partner portals.

## SUMMARY
An actor tracked here as CINNABAR ROOK (fictional) compromised a supplier's invoice portal used by
many of its customers. Since early October 2026 the portal has served a third-quarter invoice
document with a macro that installs a loader called Emberquill. Accounts-payable teams are the
main victims. Emberquill sends host details to a collection server, and the actor has also signed
in remotely from the same infrastructure. Hosts that opened the document or reached the collection
server should be isolated.

## TECHNICAL DETAILS
### Initial Access
Customers download `invoice_q3_review.docm` from partner-invoices-hub[.]example[.]com, a real
supplier portal that was compromised, so the file arrives through a trusted relationship [T1199].
### Execution
When macros are enabled, the document starts a script host that installs Emberquill
[T1204.002, T1059.005].
### Command and Control
Emberquill posts host details to eq-collect[.]example[.]org [T1071.001]. The domain resolves to
203.0.113.209, which some hosts contact directly and which was also used for remote log-ins.
