# Malvertising Campaign Pushing Fake Browser Updates ("Gorsefinch" Dropper)

## ACTIONS TO TAKE TODAY
1. Search proxy and DNS logs for the network indicators in Table 1.
2. Remove any copy of the fake updater in Table 2 from endpoints.
3. Remind staff that browsers never ask them to download updates from a web page.

## SUMMARY
Since mid-September 2026 a cluster tracked here as MOSS WREN (fictional) has bought advertising
space on popular websites and used it to redirect visitors to a page that claims their browser is
out of date. Staff in the hospitality sector who clicked "update" downloaded a dropper called
Gorsefinch, which installs a remote-access payload. Any host that reached the fake update page or
the telemetry server below should be checked for compromise.

## TECHNICAL DETAILS
### Initial Access
Visitors who clicked the malicious advert were redirected to browser-refresh-now[.]example[.]com,
a page styled as a browser warning [T1189]. The page offers `BrowserUpdate_x64.exe` for download
[T1204.002].
### Execution
When run, the dropper unpacks its payload in memory and starts it under a renamed copy of a
system process [T1036.005]. No reboot is needed.
### Command and Control
Gorsefinch registers each victim with gf-telemetry[.]example[.]net and then receives tasks over
HTTPS [T1071.001]. Several samples contact 203.0.113.118 directly, without a DNS lookup.
