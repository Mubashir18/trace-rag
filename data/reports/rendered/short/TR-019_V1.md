# USB-Borne Worm "Lichenstep" Spreading Across Shared Kiosk Workstations

## ACTIONS TO TAKE TODAY
1. Search DNS logs for the network indicators in Table 1.
2. Search EDR alerts for the worm hash in Table 2 and reimage matching kiosks.
3. Disable autorun and block removable storage on shared kiosks.

## SUMMARY
An unattributed worm called Lichenstep is spreading between shared kiosk workstations in retail
stores through USB drives used to load price lists. The worm copies itself to every drive plugged
into an infected kiosk and reports each new victim to a beacon server. So far it only collects
basic host details, but it can download further code. Kiosks that ran the worm or contacted the
beacon servers should be reimaged.

## TECHNICAL DETAILS
### Initial Access and Spread
The worm hides on USB drives as `autoplay_helper.exe` behind a shortcut that looks like the
drive's folder [T1091]. When a user opens the "folder", the worm runs and copies itself to other
drives inserted later.
### Command and Control
New infections are announced to ls-beacon[.]example[.]org; newer versions use
kiosk-telemetry-hub[.]example[.]net instead [T1071.001]. Both names resolve to 203.0.113.203.
Some kiosks with cached settings contact the IP address directly.
