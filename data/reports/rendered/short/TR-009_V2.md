# Watering-Hole Compromise of an Industry Association Site Delivering "Tansyhook"

## ACTIONS TO TAKE TODAY
1. Search proxy and DNS logs for the network indicators in Table 1.

## SUMMARY
An actor tracked here as OCHRE IBIS (fictional) compromised the events section of a professional
association's website used by law and consulting firms. Since late September 2026 the site has
loaded an extra script that profiles visitors and, for selected organisations, offers a fake
"agenda viewer". The viewer installs a backdoor called Tansyhook. Because only some visitors are
targeted, a visit alone does not prove compromise, but every visitor should be checked.

## TECHNICAL DETAILS
### Initial Access
Pages under assoc-events-portal[.]example[.]org load a script from
th-cdnjs-loader[.]example[.]net, made to look like a common JavaScript library [T1189].
### Execution
Visitors from selected networks are prompted to download `agenda_viewer.exe` to read the event
agenda [T1204.002]. The file installs Tansyhook and opens the real agenda as a decoy.
### Command and Control
Tansyhook requests short tasks from 203.0.113.148 over HTTPS [T1071.001]; the script host
th-cdnjs-loader[.]example[.]net also resolves to that address.
Note: many visitors reached the association site from an article on the legitimate news site news[.]example[.]org, and the injected script checks connectivity against the public resolver 192.0.2.10 before loading. Neither is under the actor's control.
