# Fake Shipping-Notice Phishing Delivering the "Rookfern" Info-Stealer

## ACTIONS TO TAKE TODAY
1. Search proxy and DNS logs for the network indicators in Table 1.
2. Search EDR alerts for the file hash in Table 2.
3. Reset saved browser passwords on every affected host.

## SUMMARY
An actor tracked here as BRASS KESTREL (fictional) is sending fake parcel-delivery notices to staff
at e-commerce companies. The notice says a delivery failed and links to a page for rescheduling,
which hands out a zipped "shipping notice". The file is an info-stealer called Rookfern that copies
saved passwords and browser data and uploads them to the actor. Every host that opened the
rescheduling page or uploaded data should be cleaned and its saved passwords changed.

## TECHNICAL DETAILS
### Initial Access
The lure links to parcel-reschedule[.]example[.]com [T1566.002], which delivers an archive
containing `ShipNotice.pdf.exe`, an executable with a double extension [T1036.007].
### Collection
Rookfern collects saved browser passwords and cookies [T1555.003] and screenshots of the desktop.
### Exfiltration
Collected data is uploaded to rf-exfil-store[.]example[.]net over HTTPS [T1041]. When the
domain is blocked, the stealer uploads directly to 203.0.113.151.
