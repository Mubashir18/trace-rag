## SUMMARY
A ransomware affiliate tracked here as RUSTED GANNET (fictional) has been planting links to a
"portable PDF merge" tool in search results since early September 2026. The download is a loader
called Brindlecat, which gives the affiliate a foothold that is later used to deploy ransomware.
Manufacturing companies have been hit most often. In the cases seen so far, ransomware followed the
first Brindlecat connection within four to nine days, so early detection matters.

## TECHNICAL DETAILS
### Initial Access
Users searching for a free PDF tool were led to freeutil-downloads[.]example[.]org through
poisoned search results [T1608.006]. The site serves `pdfmerge_portable.exe` [T1204.002].
### Execution and Defense Evasion
The tool works as advertised, but it also injects Brindlecat into explorer.exe [T1055] so that the
loader runs inside a trusted process.
### Command and Control
Brindlecat sends a heartbeat to bc-sync-node[.]example[.]com every few minutes over HTTPS
[T1071.001]. If the domain is blocked it falls back to 203.0.113.121.
